# Changelog

## 0.1.0 — 2026-09-08

Initial release package of Rehab Clinical Mind. Remote publication is a separate operation.

- Personalized therapist profile with scoped low / medium / high preference confidence.
- Four clinical reasoning modes, guided mode by default.
- Safety-first framework with repeated risk checks and escalation before technique discussion.
- Clinical episode learning with observation/causal confidence and generalization warnings.
- Portable Markdown memory adapter, user isolation, correction and deletion boundaries.
- Available / Accepted / Applied / Preferred knowledge states, separate from scientific evidence.
- Six references, three blank templates, four fictional examples and 20 benchmark specifications.
- Six fictional session simulations; iteration clarified empty preference tables and confidence values.
- Optional OpenAI UI metadata; no service, database, API or runtime dependency added.

See tests/test-results.md for actual execution coverage and revision retest status. No claim of clinical validation or universal host compatibility.
