# Case Learning

## Clinical Episode Memory

使用 `templates/CASE_MEMORY.md`。先临床复盘，再决定长期保存。提及病例不自动等于保存授权，用摘要代替原文。记录类型 `fictional / educational / deidentified-clinical`；前两者不计真实应用经验。

必备项：Presentation、Context、Important History、Initial Hypotheses、Assessment、Findings、Intervention、Immediate Reassessment、Short-term Follow-up、Long-term Follow-up、What Changed the Reasoning、Therapist Preference Demonstrated、Learning Point、Confidence、Generalization Warning。缺失写 unknown/not-assessed/not-followed-up，不能补成正常、阴性或成功。

## 复盘步骤

1. 重建时间顺序：最初知道什么、假设如何形成、为何选评估、当时遗漏什么。
2. 发现与解释分列；说明技术选择源于目标、证据、熟悉度、资源或患者偏好。
3. 查同条件基线和复测，分开支持与推翻原假设的结果，记录无变化和恶化。
4. 检查自然病程、期待、同时干预、负荷改变、测量误差等解释。未复测不能用「觉得舒服」填成功能改善。
5. 提炼一条情境化学习点和一个下次改进步骤，不只说对/错。
6. 生成去标识摘要供审阅，按授权保存；只把稳定习惯候选同步至画像，不复制病例全文。

## 置信度分离

- Observation Confidence：结果记录可信度，依据测量和随访完整度。
- Causal Confidence：对干预导致结果的确信；单病例通常 low，大幅改善也不能证明机制或比较优效。
- Preference Confidence：另按 Therapist Memory 评定。

重复成功可提高对「在某情境常用此策略」的把握，不自动升级为外部科学证据。保留失败和不适用情境，防止只记成功。

## 隐私最小化

不存姓名、住址、医院/单位、病历号、联系方式、精确日期、人脸及罕见可识别组合。保留临床必要年龄段、相对时间、任务类别；episode 别名不来自患者姓名。假名化仍可能被重识别，不能保证删名即匿名。无法形成充分去标识摘要时只保留通用反思。

外部搜索不用病例原文、画像或患者细节，仅用一般性临床问题。原始教材和病例不进入公开仓库、示例、issue。教育摘要不替代机构病历和法定记录。
