# Reasoning Framework

真实病例模式下，本文件为带教者的审阅框架，不是向学员主动公布的清单；按用户请求、必要阶段点评或Debrief逐步使用。建议检查/干预不产生病例结果。

## 从诉求到问题列表

1. 明确患者希望恢复的任务与可观察目标，不只看疼痛分数。
2. 通过风险门后整理分布、起病、负荷变化、诱发/缓解、昼夜/活动后反应、既往史、功能影响与恢复环境，区分观察和解释。
3. 建立最相关的 2～3 个可检验竞争假设，允许因素共存。信息太少先澄清，不为凑数编造病理。
4. 考虑关节、肌肉/肌腱、神经、动作控制、任务负荷、训练史、睡眠/生活、心理社会因素；这是备选方向，不要求每例穷举。

## 选检查，而非堆检查

每次选能改变下一步行动的 1～3 项，综合区分价值、患者负担、风险、可靠性、资源和治疗师能力。无可靠量化数据不虚构似然比、准确率、概率。

| 记录项 | 要求 |
| --- | --- |
| 评估/任务 | 安全、可重复，必要时询问治疗师熟悉度 |
| 区分目的 | 哪两个假设或哪项负荷决策 |
| 预期分支 | 什么结果让哪个方向上升/下降，下一步如何变化 |
| 局限 | 单个结果不能说明什么，是否受疼痛/疲劳/测量影响 |

特殊试验阳性改变优先级，不独立确认诊断。动作异常、肌肉紧张也可能是保护、任务适应或疼痛的结果。

## 收到结果必须更新

新发现 → 哪个假设上升/下降/不变 → 原因与剩余不确定性 → 下一项最有价值的信息。负面和无变化结果同样记录。不追问已回答问题，不为维护偏爱技术忽视反例。

停止检查依据：已有足够信息支持安全、可逆的初步策略，更多检查不大可能改变策略，已有复测与升级条件。结果矛盾且影响安全时先澄清或转介，不无限列试验。

问题列表用功能语言，例如「上楼耐受下降」「近期训练增量与恢复不匹配」「特定任务控制受限」，标明依据和优先级。不把「某肌肉一定是病因」当成事实。

## 个体化排序

先筛选安全、患者目标/意愿、适用性、证据、成本和可实施性，再考虑熟悉度。可用熟悉的术语解释，但说清实际任务。未满足适用条件的偏好方案不进入候选。手法先行可以保留，但需联系主动任务、负荷管理和复测；无必要不强加手法。

## 干预与复测闭环

干预是可修订方案，不由反应反推病因。至少包含：

- 目标与基线：同一动作、负荷、活动范围、功能表现或主观体验。
- 起始剂量依据：频率、次数/时间、强度、幅度、休息；结合刺激性、恢复、合并症和资源。信息不足只给原则，不开固定通用处方。
- 即时复测：同条件比较目标任务，记录改善/无变化/恶化和测量误差。
- 随访：查看下一次活动及次日反应，按情境明确下次复查；短时减痛不等于长期功能恢复。
- 进阶：表现和恢复稳定后一次调一个主要负荷变量；退阶：次日反应显著高于约定基线或功能下降时减量并重新评估。阈值和时间个体化，不用固定疼痛分数当通用安全线。
- 停止/转介：新风险、持续恶化或超出可解释范围时回到 Safety Core。

无变化时检查剂量、依从性、测量和原假设，不把失败自动归因于患者不配合或「深层肌肉未激活」。

## 能力与任务迁移

短时症状修改后，应按目标任务重新建立ROM、力量、耐力、速度、爆发、协调、扰动耐受、负荷耐受、信心与动作变化。暂时减少某动作不自动变永久禁忌；真实医学限制优先。运动员逐步走向实际专项和回场，按任务考虑动力链，不预设未测部位有异常。卒中围绕任务重复剂量、移动/上肢功能和家庭参与，不能只讨论肌张力。详见MSK_CASE与STROKE_CASE模板。
