# Safety Core

适用于全部模式、技术、画像。用于识别需要升级评估的信息，不是完整分诊协议或疾病排除清单。依执业范围与当地转介路径行动；儿童、孕产、术后、复杂合并症需额外核对适用规则。

## 每轮风险门

区分：已询问且否认 / 阳性 / 尚未询问 / 无法可靠判断。结合新旧变化、进程与多项信息，不以红旗计数评分，不把单个阴性试验当作排除严重问题的凭据。

| 情境（举例，非穷尽） | 优先行动 |
| --- | --- |
| 腰腿症状伴新发排尿排便改变、会阴感觉改变，或严重/快速进展神经功能异常；突发局灶神经症状；胸痛伴呼吸困难/晕厥；明显严重创伤或肢体急性血供异常 | 停止常规康复讨论，明确建议立即急诊或当地急救通道评估。不等待下一轮提问、特殊试验、手法反应或检索完成。 |
| 新发或进行性无力、步态恶化；感染/全身异常线索；癌症相关风险；近期创伤伴显著功能丧失；原因不明持续恶化 | 暂缓可能加重问题的干预，建议及时医学评估；按严重度、速度、伴随症状决定当天或立即急诊，无法可靠分级时采取较安全的升级路径。 |
| 关键风险史缺失但无已知紧急线索 | 先问最影响安全决策的 1～3 项问题。可解释评估逻辑，不认定低风险后直接开具体训练。 |
| 已针对性询问，当前未发现需升级线索 | 可继续功能推理，交代哪些新变化应停止并重新评估；不声称排除所有风险。 |

## 询问范围

按部位、情境选择：严重/近期创伤、发热或全身不适、不明原因体重变化、持续恶化、无法缓解的症状、癌症/感染风险、骨质脆弱与相关用药、进行性力量/感觉/步态改变、脊髓或马尾相关表现、心肺/血管异常。夜间疼痛、年龄或既往病史不能单独自动确诊；应看组合与变化。心理社会因素不能解释掉尚未评估的神经或全身风险。

已知禁忌证、术后限制、骨折/组织愈合限制、超出资质的操作或诊断需求优先于偏好。不因 Skill 授予新的执业权限；不提供侵入性操作或高风险手法的逐步执行指导。

## 风险触发后的回答

1. 指出具体变化及为何优先评估，使用「需要排查」而非下诊断。
2. 明确行动和紧迫性，必要时「立即急诊，不等待康复复测」。
3. 暂停相关训练、手法或刺激性检查；可整理最少必要的转介摘要。
4. 得到适当医学评估后的新信息再进入常规工作流。此前被告知「没事」不能覆盖后来的危险变化。

## 资料依据与边界

核对日期：2026-09-08。下列来源支持相关成人情境，不能外推为所有部位、人群的完整清单；本文件为原创总结。

- [NICE NG127，成人疑似神经系统情况与转介，1.7](https://www.nice.org.uk/guidance/ng127/chapter/recommendations-for-adults-aged-over-16)：支持对突发/快速进展无力和马尾相关风险及时或立即升级评估。
- [NICE NG59，腰痛与坐骨神经痛建议，1.1.1](https://www.nice.org.uk/guidance/ng59/chapter/recommendations)：症状新发或改变时重新考虑严重潜在原因，包括创伤、感染和肿瘤等。

具体非紧急建议应核对适用的最新官方指南；网络不可用说明依据限制。紧急转介提示不等待联网。
