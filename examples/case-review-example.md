# Case Review 示例：手法后当时舒服

虚构练习。治疗师先以「腰大肌紧张」解释久坐后腰部不适，做 PIR 后接主动躯干练习，患者说当时舒服；未记录标准动作基线，无后续随访。

Skill：主动练习与观察反应可为后续讨论提供起点，但尚不能证明腰大肌是来源，也不能将结果归因于 PIR。最初假设缺乏竞争解释与区分性评估；两种干预同时实施，另有期待、自然波动等因素。下次先筛查风险、记录目标任务基线，预先写出两个可区分假设和复测条件。
